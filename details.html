MỤC TIÊU HỌC LIỆU

Tài liệu nhằm hướng dẫn học môn Các công nghệ lập trình hiện đại tại Khoa CNTT, Đại học Mở Tp.HCM, dành cho hệ chính quy, từ xa, và trực tuyến trình độ đại học, hoặc người học yêu thích lập trình và các lĩnh vực có liên quan. Tài liệu hướng dẫn người học phát triển ứng dụng toàn diện, trong đó phát triển Restful API được minh hoạ thông qua công nghệ Django Rest Framework, phát triển các ứng dụng Web phía front-end với ReactJS và các ứng dụng trên thiết bị di động với React Native.

CẤU TRÚC HỌC LIỆU

  1. Chương 1. Tổng quan các xu hướng công nghệ hiện đại: chương này trình bày một số xu hướng phát triển phần mềm hiện đại, đang được quan tâm nhiều trên thị trường phát triển phần mềm.
  2. Chương 2. Phát triển Restful APIs: chương này trình bày cách thức xây dựng Restful APIs và minh hoạ chi tiết thông qua công nghệ Django Rest Framework, một công nghệ mạnh mẽ phát triển các ứng dụng thương mại của Python.
  3. Chương 3. Lập trình Javascript: chương này trình bày các kiến thức căn bản đến nâng cao về lập trình Javascript làm nền tảng dễ dàng tiếp cận chương 4 và chương 5.
  4. Chương 4. Phát triển ứng dụng Web với ReactJS: chương này trình bày phát triển Web App phía front-end, minh hoạ thông qua thư viện phổ biến ReactJS, tương tác với API đã xây dựng từ chương 2.
  5. Chương 5. Phát triển di động đa nền tảng với React Native: chương này trình bày các kiến thức căn bản phát triển ứng dụng di động đa nền tảng với React Native, tương tác với API đã xây dựng từ chương 2.
